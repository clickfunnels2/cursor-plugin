# Security

This repository is the marketplace wrapper. It contains no credentials. The MCP entry is the public ClickFunnels server at `https://agents.myclickfunnels.com/mcp`, and sign-in is OAuth 2.1 with PKCE against the user's own ClickFunnels account.

Do not open a pull request that adds an API key, client secret, or access token.

Report a vulnerability in the plugin wrapper, or in the ClickFunnels MCP server, through [ClickFunnels support](https://support.myclickfunnels.com). Please avoid filing a public issue that includes customer data or a live token.
